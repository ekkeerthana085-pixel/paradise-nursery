
# Paradise Nursery

Paradise Nursery is an online plant shop built with React and Redux Toolkit.

## Features
- Plant catalog with category filters
- Product images, descriptions, and prices
- Add products to a shopping cart
- Increase and decrease item quantities
- Remove cart items
- Calculate subtotal and total item count
- Responsive navigation and landing page

## Run the project
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.
